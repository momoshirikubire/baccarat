# App Store 用の素材

- `character-point.png` / `character-surprised.png` / `character-cheer.png`：スクリーンショットに入れた桃尻くびれちゃんのキャラ（透過 PNG）。1枚目＝指さし、2枚目＝びっくり、3枚目＝にっこり。
- 提出したスクリーンショットは Git に入れず、Mac にだけ置く（`store-assets/screens/` は .gitignore 済み）。
  - キャラ入りの最終版：2622×1206（App Store Connect の「Dynamic Island搭載iPhone（中型ディスプレイ）」）と 2868×1320
  - チップ（アプリ内課金）の審査用：`7b-tip-prices.jpg`
- アプリアイコンは `Keisen/Assets.xcassets/AppIcon.appiconset/AppIcon.png`（Gemini で作成）。
